# Application icon

The family dragon surrounds a gold branching tree: discoveries and the evolution
of capabilities. Leaf green distinguishes Darwin's Hoard from the mint Kinect icon.

- `app-icon.png`: 512 px Hub icon.
- `app-icon.ico`: Windows icon with 16, 32, 48, 64, 128 and 256 px frames.
- `darwin_hoard/static/icon-192.png`: header, favicon and PWA icon.
- `darwin_hoard/static/icon-512.png`: large PWA icon.

All sizes derive from the same artwork. The full-size master is kept in the family
Icons directory as `Darwins hoard.png`. The Hub discovers the root PNG and refreshes
its revision automatically; no Hub restart is needed.

Created on 2026-11-02 with the built-in image generation tool, using the existing
Kafka icon as a family-style reference. Brief: a leaf-green metallic circular
dragon embracing a gold tree of evolution, dark navy ground, no lettering.
